## Как запустить (и не расплакаться)

1. Unix-like ОС (Linux/macOS). Windows — WSL/VM, иначе Docker будет смотреть на вас осуждающе.  
2. Установить Docker.  
3. Клонировать репо.  
4. Собрать jar: `mvn clean package` (clean — потому что «оно же вчера работало»).  
5. Из корня: `docker-compose up`.

Локально без Docker можно на **H2** — смените профиль (см. конфиги проекта).  
Swagger обычно рядом, если Spring не обиделся на порт.
